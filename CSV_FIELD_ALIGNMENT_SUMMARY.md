# CSV Field Alignment Summary

## Overview
Successfully standardized CSV bulk upload fields to match the **AddStudent form** exactly. All CSV imports now use consistent fields across the platform.

---

## Changes Made

### 1. **csvParser.js** - Updated Field Definitions
**File:** `src/dataflow/addstudentsfromcsv/csvParser.js`

**Before (Old Fields):**
```javascript
const REQUIRED_VALUE_FIELDS = ['name', 'department'];
const OPTIONAL_FIELDS = ['email', 'phone', 'address', 'dateOfBirth', 'semester'];
```

**After (New Fields - Aligned with AddStudent Form):**
```javascript
const REQUIRED_VALUE_FIELDS = ['name', 'age', 'studentClass', 'section', 'fatherName', 'motherName'];
const OPTIONAL_FIELDS = ['fatherOccupation', 'fatherIncome', 'addressLine1', 'addressLine2', 'city', 'state', 'postalCode', 'country'];
```

**Validation Updates:**
- `validateStudent()` function updated to validate:
  - **name:** Min 2 characters (required)
  - **age:** Number between 1-100 (required)
  - **studentClass:** At least 1 character (required)
  - **section:** Must be 'A' or 'B' (required)
  - **fatherName:** Min 2 characters (required)
  - **motherName:** Min 2 characters (required)
  - All optional fields pass through without strict validation

---

### 2. **server/index.js** - Backend Validation & Student Creation
**File:** `server/index.js` (bulk-upload endpoint)

**Changes:**
1. Updated field destructuring to use new fields:
   - Removed: `email, department, phone, address, dateOfBirth, semester`
   - Added: `age, studentClass, section, fatherName, motherName, fatherOccupation, fatherIncome, addressLine1, addressLine2, city, state, postalCode, country`

2. Updated validation logic:
   - Changed from checking `name` and `department` as required
   - Now checks `name, age, studentClass, section, fatherName, motherName` as required
   - Added age range validation (1-100)
   - Added section validation (A or B only)

3. Updated roll number generation:
   - **Old approach:** Generated by department abbreviation (e.g., CS001)
   - **New approach:** Generated by class abbreviation + counter (e.g., 10A001, 12B002)
   - Benefits:
     - Roll numbers now reflect student's class
     - Cleaner logic matching academic structure
     - Easier to identify students by class from roll number

4. Updated Student document creation:
   ```javascript
   const newStudent = new Student({
     name,
     age: parsedAge,
     studentClass,
     section,
     fatherName,
     motherName,
     fatherOccupation: fatherOccupation || '',
     fatherIncome: fatherIncome || '',
     addressLine1: addressLine1 || '',
     addressLine2: addressLine2 || '',
     city: city || '',
     state: state || '',
     postalCode: postalCode || '',
     country: country || '',
     rollNumber: newRollNumber,
   });
   ```

## Testing CSV Upload

### Valid CSV Header Order:
```
name,age,studentClass,section,fatherName,motherName,fatherOccupation,fatherIncome,addressLine1,addressLine2,city,state,postalCode,country
```

**Note:** Column order is STRICT. Any reordering will result in a parsing error.

### Example Valid Row:
```
John Doe,15,10,A,Robert Doe,Jane Doe,Engineer,50000,123 Main St,Apt 4B,New York,NY,10001,United States
```

### Validation Rules:
- **name:** Required, minimum 2 characters
- **age:** Required, must be a number 1-100
- **studentClass:** Required, any value
- **section:** Required, must be A or B (case-insensitive)
- **fatherName:** Required, minimum 2 characters
- **motherName:** Required, minimum 2 characters
- **All other fields:** Optional (can be empty)
